# BRAND CONTEXT: TYREE'S AUTO DETAILING

## 1. Visual Direction & Brand Identity

- **Visual Baseline:** Mike likes his current website design. The goal is to retain and respect this core identity while noticeably improving layout clarity, spacing, photography presentation, package comparison, and the appointment request flow.
- **Palette:**
  - **Electric Cyan-Blue Accent:** `#0FA3FB` / `oklch(0.68 0.19 235)` (CTA buttons, highlight badges, primary checkmarks, focus rings)
  - **Electric Blue Glow:** `rgba(15, 163, 251, 0.28)`
  - **Jet Dark Base:** `#09090b` (Primary canvas background)
  - **Panel / Surface Raised:** `#121215` / `#18181b` (Card containers, section backgrounds)
  - **Subtle Surface Border:** `rgba(255, 255, 255, 0.08)` / `#27272a`
  - **Foreground / Text Primary:** `#f8fafc` (Clean white)
  - **Muted Text:** `#a1a1aa` (Readable contrast, 4.5:1+ accessible)
- **Typography:**
  - **Headings / Display:** Barlow (Bold, geometric, clean automotive feel)
  - **Body / Interface:** Inter (Highly readable, neutral, clean on mobile screens)
- **Tone of Voice:**
  - Direct, honest, experienced, unpretentious, meticulous, practical.
  - No corporate fluff, no exaggerated promises. Transparent about time (6–8 hours) and conditions.

## 3. Anti-Patterns to Avoid

- Overly dense AI card grids and dashboard aesthetics.
- Low-contrast text on dark backgrounds.
- Distracting excessive scroll animations or generic particle canvases.
- Stock photo models pretending to be the detailer.
- Unsubstantiated claims ("Voted best in North Carolina", "10,000 cars cleaned").
- Fake automated instant booking calendar when all appointments must be confirmed by Mike.
