# FORMS AND LEADS

Every lead path must have a clear destination.

## Default Goal
Website visitor -> lead captured -> CRM -> immediate follow-up -> booking / booked job.

## Requirements
For every form:
- define destination
- define required fields
- define success state
- define failure state
- verify spam protection
- verify mobile usability
- verify submissions reach the correct CRM/inbox
- verify tracking if applicable

## Votel
When Votel is used:
- document form integration
- document pipeline stage
- document automation trigger
- document SMS/email follow-up
- document booking handoff

## Do Not
- create dead forms
- submit nowhere
- collect unnecessary sensitive information
- expose API keys
- assume integrations work without testing

## CTA Consistency
Phone, form, quote, and booking CTAs should match the client's actual workflow.
