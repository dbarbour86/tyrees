# QA CHECKLIST

Run before launch and after major changes.

## Content
- No placeholder copy
- No invented claims
- No broadened claims: paraphrases must preserve the exact factual scope of the source
- No unsupported implications (for example, "no chemical fertilizer" must not become "chemical-free," "no synthetic sprays," "pesticide-free," "herbicide-free," or "organic")
- Substantive marketing claims are VERIFIED or SAFE PARAPHRASES; UNSUPPORTED or INFERRED claims are rewritten or removed
- Important facts can be traced to an approved business-controlled source
- If official sources conflict, flag for human review instead of guessing
- Correct business name
- Correct phone
- Correct email
- Correct service area
- Correct services
- Correct pricing if shown
- Real reviews only

## Functional
- All nav links work
- All CTA buttons work
- All forms submit
- Booking links work
- Phone links work on mobile
- Email links work
- No broken internal links
- No obvious 404s

## Responsive
Test:
- 320px
- 360px
- 390px
- tablet
- desktop

Check:
- no horizontal scroll
- no clipped text
- no overlapping elements
- no broken menus
- tap targets usable

## Technical
- no console errors
- no missing assets
- metadata present
- favicon present
- canonical correct
- sitemap works
- robots works
- schema valid
- analytics present if required

## Accessibility
- keyboard navigation works
- focus states visible
- form labels present
- alt text appropriate
- headings logical
- contrast acceptable

## Visual
- no obviously repeated template artifacts
- section rhythm feels intentional
- spacing consistent
- imagery is relevant
- no unnecessary badges/cards
- site feels specific to this business
